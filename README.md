# copy-cli-termux
CLI-App untuk salin teks atau kode dari file ke clip-board

## Struktur project:
```bash
copy-cli/
│── src/
│   ├── main.cpp         # Kode utama program
│── bin/                 # Folder output setelah kompilasi
│── scripts/
│   ├── install.sh       # Skrip instalasi global
│   ├── run.sh           # Skrip otomatisasi (dev, build, deploy)
│── .gitignore           # Mengabaikan file yang tidak perlu di Git
│── Makefile             # Build system untuk kompilasi
│── README.md            # Dokumentasi proyek
```
